# 字模格式说明

## 代码要求的格式

从 `st7789.c` 代码中可以看到：

### 1. 格式定义（第387行）：
```c
/**
 * 每个字符16行x8列，按行存储（每行1字节，共16字节）
 * 数据格式：每行8位，MSB在左（第7位），LSB在右（第0位）
 */
```

### 2. 绘制代码（第627-630行）：
```c
for(i = 0; i < 16; i++)  // 16行
{
    unsigned char row_data = font_data[i];  // 每行取1个字节
    for(j = 0; j < 8; j++)  // 8列
    {
        // 检查每一位（8位）
        color = (row_data & (0x80 >> j)) ? fg_color : bg_color;
    }
}
```

## 结论

**代码需要的是：8列 x 16行，每行1字节（8位），共16字节**

- 16行：循环16次，每次取 `font_data[i]`（1个字节）
- 8列：每行8位，从第7位（MSB）到第0位（LSB）

## 您提供的数据格式分析

您提供的数据：
```
{0xC0,0x0F,0x60,0x10,0x10,0x10,0x10,0x10,0x10,0x08,0xF0,0x07,0xE0,0x03,0x00,0x00}
```

这也是16字节，有两种可能：

### 情况1：已经是8列x16行格式
- 可以直接使用，每字节代表一行（8列）
- 第0行：0xC0
- 第1行：0x0F
- 第2行：0x60
- ...（共16行）

### 情况2：是16列x8行格式（每行2字节）
- 需要转换：提取每行的低8位或高8位
- 行0：0xC0, 0x0F → 需要选择其中一个字节
- 行1：0x60, 0x10 → 需要选择其中一个字节
- ...（共8行，需要扩展为16行）

## 建议

**如果您的数据已经是8列x16行格式（每字节一行），可以直接使用，无需转换！**

只需要将数据按顺序放入数组即可。
