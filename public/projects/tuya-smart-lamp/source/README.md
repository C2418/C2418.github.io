# 涂鸦智能台灯 · TuyaOS 应用源码

- **项目开发时间：2025 年 9 月。**
- **源码公开整理：2026 年 9 月。** 本次发布为此前项目的源码归档与文档补充，不代表项目于上传时开始开发。

围绕台灯调光体验的应用项目，集成冷暖双路 PWM、亮度与色温渐变、旋转编码器、触摸控制、涂鸦 DP 指令处理和离线操作。

## 平台与功能

构建脚本目标为 BK7231N，原脚本环境路径标注 TuyaOS 3.3.44。这里只包含应用目录，**不包含完整 TuyaOS SDK、交叉编译器、设备授权或可直接烧录的固件**。

| 模块 | 代码入口 | 内容 |
| --- | --- | --- |
| 灯光控制 | `src/tuya_app_main.c` | 双路 PWM、渐变线程、配网状态与控制协调 |
| App 指令 | `src/dp_process.c` | 开关、亮度、色温、倒计时等 DP 处理与状态上报 |
| 旋钮 | `src/encoder.c` | 编码器采样与按键事件 |
| 触摸 | `src/touch.c` | 触摸输入处理 |
| 离线操作 | `src/offline_mode.c` | 本地控制、运行模式及相关状态处理 |
| 构建 | `local.mk`、`build_next.sh` | 应用源码收集与 SDK 构建脚本入口 |

源码配置 PWM 频率为 10 kHz，渐变更新间隔为 20 ms；这些是程序配置值，不是本次测得的性能指标。App DP 中亮度范围为 10–1000，色温控制值为 0–1000；色温值不是开尔文温度。

## 复现准备

1. 准备与 BK7231N 应用兼容的 TuyaOS SDK、工具链和开发环境，核对实际板卡型号。
2. 将本目录集成到 SDK 的 `apps/9999`，或者同步修改 `build_next.sh` 中的应用名与路径。脚本依赖 SDK 的 `vendor/bk7231n/tuyaos/build.sh`，不能独立运行。
3. 把 `src/tuya_app_main.c` 中的 `YOUR_PID` 替换为自己的产品 ID，并使平台 DP 定义与 `dp_process.c` 对齐。
4. 使用自己的设备授权流程；注释中的 UUID/AuthKey 仅保留占位符，不应直接取消注释使用。
5. 核对 PWM 通道、编码器引脚（P15/P17/P9）、触摸引脚（P22）及驱动电路。引脚依据现有源码，接线仍须以实际硬件为准。
6. 使用匹配 SDK 的构建流程编译，再验证本地控制、App 控制、断网、重新配网和掉电恢复。

本次未重新编译或烧录，SDK 兼容性、完整 DP 面板与硬件效果需要在目标环境验证。未附原理图、PCB、实物照片和实测数据。

## 验证边界

渐变启动函数与渐变线程共享多项状态；静态阅读发现旧渐变结束和新渐变启动交错时，存在覆盖新状态的竞争风险，需通过同步机制与连续操作压测进一步处理。当前源码不宣称零竞争、无闪烁或量产稳定性。

建议重点检查：App 与旋钮快速交替操作、渐变中再次开关、断网后本地控制、联网恢复、掉电记忆和配网状态切换。
